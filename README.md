## 💙 Sobre o projeto

Sistema web desenvolvido para facilitar o gerenciamento de uma assistência técnica de celulares.

Permite organizar clientes, aparelhos e agendamentos em um único lugar.

---

## 📂 Explore o sistema

<details>
<summary>👤 Gerenciamento de Clientes</summary>

### Funcionalidades
- Cadastro de clientes
- Pesquisa de clientes
- Edição de informações
- Organização dos registros

</details>

<details>
<summary>📱 Gerenciamento de Aparelhos</summary>

### Funcionalidades

- Identificação por IMEI
- Atualização dos dados
- Consulta de aparelhos

</details>

<details>
<summary>📅 Agendamentos</summary>

### Funcionalidades

- Consulta dos registros
- Organização dos atendimentos

</details>

<details>

### Funcionalidades

## 🚀 Como executar

<details>
<summary>▶️ Clique para ver o passo a passo</summary>

**1.** Baixe o projeto.

**2.** Abra a pasta no VS Code.

**3.** Instale as dependências:

```bash
pip install flask mysql-connector-python
```

**4.** Configure o banco de dados MySQL.

**5.** Execute o arquivo principal do projeto.

**6.** Abra no navegador o endereço exibido no terminal.
